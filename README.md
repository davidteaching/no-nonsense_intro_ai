## 💬 How to Give Feedback / Cara Memberikan Kritik & Saran

| English | Indonesia |
| :--- | :--- |
| To keep our conversations organized, **all feedback, suggestions, ideas, and general chats are hosted via GitHub Discussions.** | Untuk menjaga agar obrolan tetap rapi, **semua kritik, saran, ide, maupun diskusi santai dilakukan melalui GitHub Discussions.** |

### 🛠️ Steps to participate / Langkah untuk berpartisipasi:
1. Go to the **[Discussions](https://github.com/davidteaching/no-nonsense_intro_ai/discussions)** tab at the top of this repository page.
   *(Buka tab **Discussions** yang ada di bagian atas halaman repositori ini.)*
2. Choose the category that fits your feedback (e.g., *General, Ideas, Q&A,* or *Feedback*).
   *(Pilih kategori yang sesuai dengan masukan Anda, misal: General, Ideas, Q&A, atau Feedback.)*
3. Click the **New Discussion** button.
   *(Klik tombol **New Discussion**.)*
4. Type a clear title (e.g., *Feedback on Chapter 3 plot*) and write your thoughts.
   *(Tuliskan judul yang jelas, contoh: Saran alur untuk Bab 3, dan sampaikan masukan Anda.)*
5. Click **Start Discussion**.
   *(Klik **Start Discussion**.)*
